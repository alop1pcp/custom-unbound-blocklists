# Custom Unbound blocklists
A collection of blocklists for use with Unbound DNS.

## Usage
1. Open any blocklist under [blocklists](blocklists/) and click "view raw".
2. Copy the URL and create a new blocklist entry in unbound.

## Implemented blocklists
- [x] Port of DuckDuckGo app tracking protection blocklist from [here](https://github.com/duckduckgo/tracker-blocklists/tree/main/app).
